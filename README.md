# PowerShell-monitoring-toolkit
PowerShell-based monitoring and automation scripts created for system administration, troubleshooting, and IT operations practice.
## Scripts Included
### CpuMonitor.ps1
Monitors CPU and memory usage and alerts when CPU usage exceeds threshold values. 
### ProcessMonitor.ps1
Displays top CPU and memory consuming processes in real time. 
### OpenPorts.ps1
Lists listening TCP ports and maps them to running processes. 
### FaileLoginAttempts.ps1
Parses Windows Security Event Logs to identify failed login attempts and exports results to CSV.
### SystemErrors.ps1
Retrieves recent Windows system errors from Event Viewer logs for troubleshooting.
### ScheduleTasksReport.ps1
Generates a report of scheduled tasks and their current states.
### DiskCleanUp.ps1
Removes temporary files to help free disk space and improve system performance.
